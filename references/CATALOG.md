## 问不到时

- 检索 0 命中 → Skill 明确说「库中未找到」，并可提供常识性做法但必须标注「非本库内容」。
- 命中但 `extraction=scanned_or_oversize` / 图片 / 视频 / exe → 只给原件路径（占位符形式），需人工打开查看。
- 涉及罂粟壳、罂粟油等违禁成分的配方 → 拒答可操作版本，见 `CAVEATS.md`。
