# 资料可靠性与食品安全红线

**给出任何可执行配方前必读本文件。** 本库是 2005–2011 年前后的网盘合集，主体是小吃加盟/技术资料站（sicang8.com、365小吃技术网）的打包资料，不是标准工艺文件、不是检验报告、不是法规依据。

## 一、可靠性分级

| 级别 | 内容 | 可信度与用法 |
|---|---|---|
| A | 正式出版物文本型 PDF：`中国名菜` 16 册、`《中华名特风味小吃》`上下、`菜谱.八大菜系.*`、`菜谱.微波炉菜系大全`、`中国野菜食谱大全` | 有编辑审校、剂量规范，可作为菜系做法与工艺关键的可靠引用 |
| B | 署名厨师技术文章：张飞牛肉、无渣红油火锅、鱼汤面、刘氏锅贴、扬州三丁包等（含"试制点评/作者回复"） | 有实操验证记录，可信度较高；注意试制点评里常指出原方偏差（如"口味偏淡""烤半小时不够，需 50 min"） |
| C | 加盟/破解/网购技术资料：赵大妈系列、麦多馅饼、土家酱香饼、奇味涮烫、过桥米线破解版、各类"绝密配方" | 带招商导向，含大量商品代号和"适量"，**必须标注需试制验证**，不可直接照搬量产 |
| D | 图片配方、扫描 PDF、视频、exe 电子书 | 无法核对文字，只提供路径，不推断内容 |

## 二、硬性红线

1. **违禁添加物**：资料中明确出现 `罂粟油`、`澳宴奇婴粟籽油脂粉`（罂粟籽油脂粉）、`罂粟壳` 类表述（见 `[id:724]` 土家酱香饼酱料、`[id:34]` 麦多料包备注）。罂粟壳/罂粟籽属毒品原植物，加入食品违反《食品安全法》并可能涉刑。**遇到含此类成分的配方：拒绝提供可操作版本，明确指出违法，给出以合法香辛料（花椒、八角、孜然、白芷等）重建风味的替代思路。**
2. **食品添加剂**：山梨酸钾、辣椒红/油溶一号色素、火锅飘香剂、粉汤飘香王、特鲜1号、鲜味王、牛肉/鸡肉香精、嫩肉粉、复合磷酸盐、亚硝酸盐、明矾、超甜素/蛋白糖、消泡剂、面包改良剂、无铝膨松剂等在本库中普遍出现且常写"适量"。回答时提示：按现行 **GB 2760** 核对允许使用的食品类别与最大使用量，按 **GB 2760 / GB 2762** 核对污染物与重金属限量；"[id:848] 骨肉相连"给出了复合磷酸盐 ≤5.0 g/kg、亚硝酸盐按 GB 2760 执行等理化指标，可作为对照样例，但年代较早须以现行标准为准。
3. **中药材入菜**：红参、黄芪、灵芝、天麻、当归、党参、沙参、五加皮等出现在八珍烤鸡、烧鸡公、牛骨头、药膳菜谱中。提示按国家"按照传统既是食品又是中药材的物质目录"核对，非目录物质不得作普通食品原料；不要转述"滋补/疗效/预防疾病"等保健或医疗宣称。
4. **长期存放与老汤**：奇味涮烫底料标注"常温 8–15 ℃ 存放 8–16 个月"、料包连用 3–4 次、臭卤自然发酵一年、老汤循环使用。这些是家庭/小店经验做法，存在微生物与油脂氧化风险，回答时提示冷藏、限时、定期理化与微生物检测的必要性。
5. **宣传话术**："绝密""祖传""专利配方""技术破解版""正宗""加盟技术资料"是营销措辞，不是事实背书。不得在答案里替资料宣称正宗或功效。
6. **价格与法规时效**：`利润分析.doc` 按煎饼 2 元/张、房租 600 元/月测算，`珍薯园开店投资方案.doc` 按 4 万元投资测算，均为 2010 年前后数据；厂家电话、供应商品牌、专利状态均已过时，涉及成本结论必须注明"原始测算年份，需按现行物价重算"。

## 三、数据质量坑

- **单位混乱**：斤/两/钱/克/毫升/大勺/包混用；统一换算 1 斤=500 g、1 两=50 g、1 钱=5 g。
- **OCR 讹误**：`干克`=千克、`犯厘米`/`2oo克`=200 克、`鄙县豆瓣`=郫县豆瓣、`滋粑辣椒`=糍粑辣椒、`耗牛`=牦牛、`枚肉`=梅肉/瘦肉、`特鲜一号/鲜味王/飘香王` 为商品代号。数量级错误会直接毁掉配方，回答前核对上下文。
- **模糊量词**："适量""少许""一包""少许飘香剂""根据当地口味"在 C 级资料里极常见，导致配方不可复现；明确告知用户这些环节必须靠试制确定。
- **同题多版本冲突**：牛骨头配方 `[id:622]` 与 `[id:625]` 用量不一致（同一份资料自称"经过三次改动，以本资料为准"）；土家酱香饼 `[id:724]` 与 `[id:728]` 是两套独立配方；油条有 3 个版本。遇到冲突时并列给出，不要擅自合并成一个"标准答案"。
- **重复文件**：`御品轩`、`麦多馅饼`、`刨冰配方`、`八宝玫瑰镜糕` 各有两份同内容副本，已在索引 `dup_of` 标记。

## 四、回答规范

1. 给配比时附 `[id:NNN]` 与文件名，说明"资料库记录的做法"。
2. 换算单位、修正错字、标出范围值和"适量"项。
3. 凡涉及添加剂、中药材、长期存放、商业销售，附一句具体合规提醒（引用现行 GB 2760 等，不要泛泛说"注意安全"）。
4. 建议小批量试制并按当地口味调整；B 级资料的"试制点评"优先一并给出。
5. 不把资料库内容再分发或商用：扫描书籍、杂志电子版、加盟资料涉及版权；仓库公开仅作检索方法展示，正文语料仅供个人学习参考，权利人提出异议时应删除对应内容。
6. 检索不到就说"库中未找到"；补充通用菜谱知识时必须标明"非本库内容"。
