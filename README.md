# chinese-recipe-archive

把本机一份 **7.48 GiB / 860 文件** 的中式小吃与菜谱资料库，蒸馏成一个可被 WorkBuddy / Agent 直接调用的 Skill：
**可检索索引 + 全文语料 + 检索脚本 + 人工提炼的配方精要**，而不是把 7.5 GiB 原件搬进仓库。

原始资料库全程只读，仓库里**不包含**任何图片、视频、扫描书、exe 原件，只有元数据与提取出的文本。

## 目录结构

| 路径 | 内容 |
|---|---|
| `SKILL.md` | Skill 入口：触发条件、四步工作流、关键约束、维护命令 |
| `data/index.json` | 860 条文件元数据（路径、类别、类型、大小、提取状态、去重标记） |
| `data/corpus.jsonl` | 140 份可提取正文，约 342 万字，按文件 `id` 索引 |
| `scripts/build_index.py` | 重建索引：GB18030 文本、OLE piece table 解老式 `.doc`、pypdf 抽中文 PDF 文本层 |
| `scripts/search.py` | 关键词检索、`--show <id>` 读全文、`--stats`、按类型/类别过滤 |
| `references/RECIPES.md` | 蒸馏成果：通用工艺规律 + 8 类主题配比速查，每条带 `[id]` 可回溯原文 |
| `references/CATALOG.md` | **配方总目录**：12 类主题逐条列出可问的配方名与 `[id]`，附示例问句 |
| `references/INDEX.md` | 顶层目录导航、大文件清单、特殊载体说明 |
| `references/CAVEATS.md` | 资料可靠性 A–D 分级与食品安全合规红线 |

## 安装

把本仓库克隆/复制到用户级 Skill 目录：

```
~/.workbuddy/skills/chinese-recipe-archive/
```

之后在会话中直接问「兰州牛肉面汤料比例」「火锅底料怎么炒」「有哪些配方可以问」即可触发。不知道能问什么时，先看上面的主题表或 `references/CATALOG.md`。

> **配置资料库根目录**：`index.json` 中的 `root` / `abs` 一律写成占位符 `<RECIPE_ARCHIVE_ROOT>`，仓库不含任何机器相关的绝对路径。若要在本机直接打开原件，二选一：
>
> 1. 在 skill 目录新建 `.local_root`，写入资料库根目录（已加入 `.gitignore`，不会入库）；
> 2. 或设置环境变量 `RECIPE_ARCHIVE_ROOT`。
>
> `search.py` 输出「原件」时自动还原为绝对路径；未配置则原样显示占位符。原库位置变动时重建索引：
>
> ```bash
> python scripts/build_index.py --root "D://你的路径//配方"
> ```

## 命令行用法

```bash
python scripts/search.py "胡辣汤 洗面" --kind text
python scripts/search.py "火锅底料" --kind text --limit 8 --context 120
python scripts/search.py "油条" --kind video
python scripts/search.py --show 831 --chars 3000
python scripts/search.py --stats
```

依赖：`pypdf`（PDF 文本层）、`olefile`（老式 `.doc`）。缺失时脚本仍可运行，只是跳过对应格式。

## 数据边界

- 图片配方、扫描 PDF、视频、`exe/chm` 打包资料**只给路径**，不做 OCR / 转写 / 解压，需打开原件查看。
- 检索不到时 Skill 会明确说「库中未找到」，不会用通用菜谱知识冒充库内配方。

## 合规声明

资料主要是 2005–2011 年的网购 / 加盟 / 「破解版」技术资料，存在以下风险，本仓库仅作**资料整理与文本检索研究**，不构成生产指导：

1. **版权**：正文语料提取自第三方资料，权利归属原作者。仓库公开仅作索引与检索方法展示，**请勿转载、商用或再分发语料**；公开意味着内容可能已被抓取、无法撤回。若权利人提出异议，请删除对应语料。
2. **违禁成分**：原文含罂粟壳 / 罂粟油 / 罂粟籽油脂粉等违法添加物，Skill 已写死规则拒答此类可操作配方。
3. **食品安全**：配比常有「适量」、商品代号（特鲜 1 号、飘香王）、单位混乱；食品添加剂须按现行 **GB 2760** 核对，任何配比都应小批量试制验证。
